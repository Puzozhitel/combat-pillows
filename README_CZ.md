# Combat Pillows (Bulánci): Enhanced Edition

[![Мультиплеер](https://img.shields.io/badge/мультиплеер-Интернет%20%7C%20LAN%20%7C%20Steam%20Remote%20Play-red.svg)](https://github.com/Puzozhitel/combat-pillows)

**Combat Pillows (Bulánci): Enhanced Edition** je komunitní verze legendární české akční 2D hry z roku 2001 od studia **SleepTeam**, postavená na poslední dostupné verzi.

Tento projekt přináší hlubokou optimalizaci originálního Win32 enginu: nativní podpora Windows 10/11, globální online multiplayer přes internet, podpora libovolného rozlišení obrazovky, neomezené vlastní mapy a vestavěný automatický aktualizátor. Vše při zachování 100% autentičnosti fyziky a hratelnosti.

---

## ✨ Klíčové vlastnosti

* 🌐 **Globální online multiplayer:** Hrajte přes internet bez nutnosti složitého nastavování routeru (UPnP) nebo VPN.
* 🎮 **Steam Remote Play Together:** Integrovaná podpora Steam API. Stačí spustit hru při zapnutém Steamu a můžete využívat streamování a vzdálený multiplayer s přáteli.
* 🖥️ **Moderní systémy a displeje:** Ideální běh na Windows 10/11, podpora širokoúhlých monitorů, 4K a vysokých FPS (díky `cnc-ddraw`).
* 🗺️ **Odemčené mapy + podpora uživatelských úrovní:** Všechny mapy jsou odemčené a můžete přidávat vlastní `.eap` soubory.
* 🔄 **Vestavěný automatický aktualizátor:** Automatická kontrola a instalace aktualizací.
* 📜 **Věrnost originálu:** Obnovené básničky v hlavní nabídce, HD fonty a oprava chyb původního enginu.
* 🌍 **Tři jazykové verze:** 🇨🇿 Bulánci, 🇬🇧 Combat Pillows, 🇷🇺 Боевые Подушки.

## 📥 Rychlý start

1. Stáhněte si nejnovější verzi ze sekce [**Releases**](https://github.com/Puzozhitel/combat-pillows/releases).
2. Stáhněte si přímo spustitelný soubor (`.exe`) pro váš jazyk:
   * `Bulanci-<verze>.exe` — Česká verze
   * `CombatPillows-EN-<verze>.exe` — Anglická verze
   * `CombatPillows-RU-<verze>.exe` — Ruská verze
3. Spusťte stažený soubor přímo. Není třeba nic instalovat ani rozbalovat.

## 🕹️ Multiplayer Guide

### 1. Online Multiplayer (Direct IP / UPnP)
1. **Host** vytvoří hru v hlavním menu.
2. Integrovaný modul automaticky otevře potřebný port (UPnP) a zobrazí veřejnou IP adresu.
3. Druhý hráč zvolí **Multiplayer -> Připojit**, zadá IP adresu hostitele a připojí se.

### 2. Steam Remote Play Together
Tato verze obsahuje integrovanou podporu Steam API. Pro použití Steam Remote Play Together:
1. Ujistěte se, že máte na počítači spuštěný Steam.
2. Spusťte spustitelný soubor hry (`CombatPillows-*.exe`).
3. Otevřete Steam Overlay (`Shift+Tab`), klikněte pravým tlačítkem na přítele a zvolte **"Remote Play Together"**. Steam hru automaticky detekuje a umožní vám pozvat přátele.

[![Multiplayer](https://img.shields.io/badge/multiplayer-Online%20%7C%20LAN%20%7C%20Steam%20Remote%20Play-red.svg)](https://github.com/Puzozhitel/combat-pillows)

**Combat Pillows (Bulánci): Enhanced Edition** je komunitní verze legendární české akční 2D hry z roku 2001 od studia **SleepTeam**, postavená na poslední dostupné verzi.

Tento projekt přináší hlubokou optimalizaci originálního Win32 enginu: nativní podpora Windows 10/11, globální online multiplayer přes internet, podpora libovolného rozlišení obrazovky, neomezené vlastní mapy a vestavěný automatický aktualizátor. Vše při zachování 100% autentičnosti fyziky a hratelnosti.

---

## ✨ Klíčové vlastnosti

* 🌐 **Globální online multiplayer:** Hrajte přes internet bez nutnosti složitého nastavování routeru (UPnP) nebo VPN.
* 🎮 **Steam Remote Play Together:** Podpora pro hraní split-screen multiplayeru s přáteli přes Steam.
* 🖥️ **Moderní systémy a displeje:** Ideální běh na Windows 10/11, podpora širokoúhlých monitorů, 4K a vysokých FPS (díky `cnc-ddraw`).
* 🗺️ **Odemčené mapy + podpora uživatelských úrovní:** Všechny mapy jsou odemčené a můžete přidávat vlastní `.eap` soubory.
* 🔄 **Vestavěný automatický aktualizátor:** Automatická kontrola a instalace aktualizací.
* 📜 **Věrnost originálu:** Obnovené básničky v hlavní nabídce, HD fonty a oprava chyb původního enginu.
* 🌍 **Tři jazykové verze:** 🇨🇿 Bulánci, 🇬🇧 Combat Pillows, 🇷🇺 Боевые Подушки.

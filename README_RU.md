**Combat Pillows (Bulánci): Enhanced Edition** — это ультимативное издание от сообщества, созданное для сохранения и модернизации легендарного культового 2D-шутера 2001 года от студии **SleepTeam**, на базе последней доступной в Сети версии.

Проект представляет собой глубокий реверс-инжиниринг оригинального Win32-движка: нативная поддержка современных ОС (Windows 10/11), полноценный онлайн-мультиплеер через Интернет, масштабирование под любые разрешения экранов, снятие ограничений на карты и встроенный автоапдейтер прямо из интерфейса игры. При этом на 100% сохранены аутентичный геймплей, физика и атмосфера оригинала.

---

## ✨ Ключевые особенности

* 🌐 **Глобальный онлайн-мультиплеер:** Играйте с друзьями через Интернет по всему миру без сторонних программ (Hamachi/Radmin) и без ручной настройки роутера. Встроенный модуль UPnP автоматически открывает порты, а встроенный Server Browser помогает находить открытые игры.
* 🎮 **Поддержка Steam Remote Play Together:** Играйте по сети в режиме разделенного экрана с друзьями из Steam по одной копии игры.
* 🖥️ **Современные системы и любые экраны:** Идеальная работа на Windows 10 и Windows 11 благодаря интеграции `cnc-ddraw`. Поддержка любых современных разрешений (1080p, 1440p, 4K, ультраширокие мониторы), целочисленное масштабирование без размытия, плавные 60 FPS, оконный режим без рамок и ретро-шейдеры (CRT/xBRZ).
* 🗺️ **Разблокировка всех карт + кастомные уровни:** Все стандартные карты открыты с самого начала. Лимиты движка пропатчены — теперь можно добавлять неограниченное количество пользовательских карт (.eap файлы).
* 🔄 **Встроенный автоапдейтер:** Проверка обновлений через GitHub Releases API (фоновая незаметная проверка при старте и ручная кнопка в меню выхода). Обновление и перезапуск с автоматическим сохранением резервной копии старой версии в папку `old\`.
* 📜 **Восстановленный контент и типографика:** Восстановлена бегущая строка со стихами в главном меню (оригинальная чешская поэзия), улучшена чёткость шрифтов (HD 1px пиксельная типографика), исправлены тайминги и пропорции сплэш-экранов.
* 🌍 **Три языковые версии:**
  * 🇨🇿 **Bulánci** (Оригинальная чешская)
  * 🇬🇧 **Combat Pillows** (Английская)
  * 🇷🇺 **Боевые Подушки** (Русская)
* 🐛 **Исправление багов оригинала:** Устранены вылеты DirectDraw на современных видеокартах, зависания при Alt+Tab и заикания звукового буфера.
* 📦 **100% Portable:** Игра не требует установки, не засоряет реестр и не зависит от сторонних библиотек. Распаковал и играешь.

## 📥 Быстрый старт

1. Перейдите в раздел [**Releases**](https://github.com/Puzozhitel/combat-pillows/releases) и скачайте архив свежей версии.
2. Распакуйте архив в любую удобную папку (например, `C:\Games\CombatPillows`).
3. Запустите файл на нужном вам языке.

* **Оригинальная игра:** Разработана студией **SleepTeam** (2001). Все авторские права на оригинальные ресурсы, персонажей и звуки принадлежат их законным авторам.
* **Enhanced Edition:** Некоммерческий открытый проект сообщества, созданный исключительно с целью сохранения классической игры и обеспечения её работоспособности на современных компьютерах.
